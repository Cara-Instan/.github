Contributing to CaraInstan (CI.)

Thank you for wanting to help build CaraInstan! Here is how you can get involved:

## How to Contribute Code
1. **Fork** this repository to your own GitHub account.
2. Create a new branch for your feature or bug fix (`git checkout -b feature-name`).
3. Commit your changes and push them to your fork.
4. Open a **Pull Request** against our `main` branch. 

*Note: All Pull Requests require an review and approval from a Core Maintainer before merging.*

## Want to join the Triage Team?
If you want to help us manage issues, label incoming requests, and guide new contributors, please open an issue with the tag `[Triage Team Application]` and tell us a bit about yourself!
